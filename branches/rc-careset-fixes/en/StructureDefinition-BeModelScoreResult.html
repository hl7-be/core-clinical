Logical Model: BeScoreResult model

Official URL: https://www.ehealth.fgov.be/standards/fhir/core-clinical/StructureDefinition/BeModelScoreResult Version: 1.4.0
Active as of 2026-10-15 Computable Name: BeModelScoreResult
Other Identifiers: OID:2.16.840.1.113883.4.642.40.200.5.42.19

Logical model for the BeScoreResult CareSet - the result of a standardised assessment scale (score) taken for a patient.

Usages:

  • This Logical Model is not used by any profiles in this Specification
