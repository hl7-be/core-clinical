CodeSystem: BelRAI Score Code System

Official URL: https://www.ehealth.fgov.be/standards/fhir/core-clinical/CodeSystem/be-cs-belrai-score Version: 1.2.0
Active as of 2026-07-16 Computable Name: BeCSBelraiScore

Codes identifying each BelRAI scoring scale/screener, used as Observation.code.

This Code system is referenced in the definition of the following value sets:
